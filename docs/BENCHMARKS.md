# 实测基准（Benchmarks）

本页所有数字均来自 RK3568 实板运行的可复核证据（结果目录 + SHA-256 清单 + 结构化日志），
不做任何估算或换算。复现方法见各表"判据"列。

## 1. 长稳阶梯（2026-09-29 ~ 10-05，同一二进制 P133 修复版）

| 阶段 | 时长 | 退出 | 管线错误 | 恢复次数 | OSD 叠加 | 跳帧 | 推流丢包 |
|---|---|---|---|---|---|---|---|
| 冒烟 | 120 s | 0 | 0 | 0 | 475/475 | 0 | 0 |
| 短稳 | 2 h | 0 | 0 | 0 | 27187/27187 | 0 | 0 |
| 中稳 | 12 h | 0 | 0 | 0 | 156545 | 1 | 0 |
| **长稳** | **120 h** | **0** | **0** | **0** | **1558546** | **17** | **0 / 24,537,112** |

- 120 h = 连续 432,000 秒**单次运行零重启**，进程优雅收尾（`run_duration_elapsed`）；
- 跳帧率 17/1,558,563 = **0.0011%**，且与"过期检测丢弃"计数严格 1:1（宁可不画、不画错）；
- 队列账目：音频 / 推理 / 推流三队列丢弃为 **0**；编码入口队列 1311/4,290,683 = 0.031%
  （由 4 帧深队列在帧率抖动时按策略丢旧，属设计行为）；
- 内核：120 h 内 `dmesg` 增量仅一条网卡看门狗告警（与推流无关，已归档为观察项），
  无 oops / lockup / 驱动报错。

## 2. 端到端延迟（120 h 全程分位数，单位 ms）

| 阶段 | p50 | p95 | p99 |
|---|---|---|---|
| 视频解码（MJPEG→RGB） | 31.5 | 34.6 | 37.8 |
| NPU 推理（YOLOv5s 640） | 120.6 | 123.4 | 125.7 |
| **OSD 叠加（CPU 绘制）** | **1.7** | **2.3** | **2.5** |
| 视频编码（MPP H.264） | 9.9 | 10.8 | 11.3 |
| 音频编码（FFmpeg AAC） | 2.8 | 3.8 | 4.5 |
| 解码+编码全链路 | 30.3 | 32.7 | 33.9 |

- 推理 5 fps 限速下 p99 仍比帧间隔（200 ms）低 36%，叠加 p99 2.5 ms ≪ 33 ms 帧周期；
- 板端播放端到端延迟（ZLMediaKit WebRTC，同源时钟法）：**0.3 ~ 0.7 s**，最差 1.1 s。

## 6. 复现判据

- 冒烟/长稳：`tools/board_osd_run.sh smoke|soak <config> <seconds>` →
  结果目录内 `result.txt`（退出码与计数）+ `errors.log` + `dmesg.before/after` 比对 +
  `evidence.sha256` 校验；
- PC 测试：`tools/build_windows.ps1`（Windows）或 `ctest --preset debug|asan`；
- 延迟分位：运行结束的 `application_stopped` 事件内嵌 `latency_us` 全量分位。
