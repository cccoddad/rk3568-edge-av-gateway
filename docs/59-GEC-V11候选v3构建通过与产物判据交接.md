## 3. v3 节点验证

结构化读取确认：

- `serial0`、`serial1` 为 `okay`；
- `mmc3=/dwmmc@fe000000`、`sdmmc2`、`wireless_wlan`、`wireless_bluetooth` 为 `disabled`；
- v3 继承 v2 已通过的 GMAC1 和 IO 电源域修正。

## 4. 边界

这证明的是主机上可由 SDK 正常生成保守有线/恢复候选，不是 GEC V11 整板 5.10 已启动。Wi-Fi、显示、
摄像头、音频、MPP/RGA/RKNN ABI 仍未在 5.10 候选上板验证；当前 FIT 禁止刷写。

对带 `#include` 的 DTS 源码直接运行 `dtc -I dts` 会因跳过 C 预处理而失败，不能替代 SDK 内核路径验证。

v3 的 DTS、DTB、Image、FIT `boot.img`、defconfig、`.config` 和构建日志随后已打包到 Windows 共享目录，
归档与 SHA-256 见第 60 号交接。
