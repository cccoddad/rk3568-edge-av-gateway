# GEC V11 启动节点差异锁定与候选 v3 交接

更新日期：2026-09-03

## 1. 一致项

v2 与 factory 的 `chosen/bootargs` 一致，根分区均为 `PARTUUID=614e0000-0000`；eMMC 主控制器
`mmc0=/sdhci@fe310000` 均为 `okay`、8 位、不可移除；USB DWC3/Host 控制器地址及 `otg/host` 模式一致；
RK809 PMIC 节点一致。

## 2. 差异项

- factory `serial0`、`serial1` 为 `okay`，v2 均为 `disabled`；
- 5.10 EVB1 的 Wi-Fi/SDIO 位于 `sdmmc2=/dwmmc@fe000000`（aliases `mmc3`），带 EVB `ap6398s`
  和 `mmc-pwrseq`；
- GEC factory 的 Wi-Fi/SDIO 位于 `sdmmc1=/dwmmc@fe2c0000`（aliases `mmc2`），带 RTL8723DS 资料，
  而 `fe000000` 禁用。

证据目录为 `evidence/mmc-serial-v3-20260903-182244`，报告 SHA-256 为
`5c8bcb308e052bc6b3ced6744460f6e30189eb9c3551b11f3d939898d07ef034`；5.10 源码上下文目录为
`evidence/mmc-serial-source-20260903-183020`，上下文 SHA-256 为
`00d52273c2ad4c45219eaa0a4ea90b1d7d60997572f6c1593d7879bf7d58b7cd`。

## 3. 保守候选 v3

当前网关使用 USB 摄像头、USB 音频和有线 GMAC1，不依赖 Wi-Fi。v3 仅：

1. `&uart0 { status = "okay"; };`
2. `&uart1 { status = "okay"; };`
3. 禁用 EVB 的 `&sdmmc2`、`&wireless_wlan`、`&wireless_bluetooth`，避免错误 Wi-Fi 控制器和 GPIO
   时序被启用。

v3 不声称 GEC Wi-Fi 已适配；RTL8723DS 到 `sdmmc1` 的正式移植另行处理。v3 的目标是保留有线网关、
提高首次启动可观察性并避免错误无线时序。

## 4. 边界与下一步

上述是基于公开 factory 的保守候选，不是机构原厂配置。下一步创建新 DTS/defconfig，离线编译 Image、DTB、
FIT boot，并反编译确认串口和无线节点状态；构建通过后仍需用户明确确认，才能考虑首次上板。
