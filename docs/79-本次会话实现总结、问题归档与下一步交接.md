   include EVB1 Linux 参考板）；
3. **验证**：DTC 编译 + fdtget 结构门禁（沿用既有流程）→ 重打 FIT（zboot.its）→ 刷入；
4. **同时部署模块**：把 5.10 的 `RTL8723DS.ko`/`goodix.ko` 替换 rootfs
   `/system/lib/modules/` 同名文件（rootfs 可写有备份），或改 init 脚本指向 /userdata；
5. **验收**：屏亮（演示动画）、触摸出坐标（evtest）、`wlan0` 出现并能扫描/连网；
